# Docker Host Skill

## Connection

- **Host:** `10.0.10.10` (user `root`)
- **Tool:** `ssh-mcp`, always with `profile: "docker-host"`
- **Config:** `~/.config/ssh-mcp/config.toml` (generated by `startup.sh`, not in the repo)

## Rule: never raw SSH

Never call `ssh` from the local shell. Use the `ssh-mcp` tools with
`profile: "docker-host"`:

| Task | Tool |
|------|------|
| Run any command | `run-command({profile:"docker-host", command:"..."})` |
| Read-only command | `read-command({profile:"docker-host", command:"..."})` |
| Command with sudo | `privileged-command({profile:"docker-host", command:"..."})` |
| List a directory | `sftp-list({profile:"docker-host", remotePath:"/etc/docker"})` |
| Read / write a small text file | `sftp-download` / `sftp-upload` |
| Large or binary file | `sftp-download-file` / `sftp-upload-file` |

The `docker-host` profile runs with `role=admin`, `approvalPolicy=auto`, so
`run-command` covers everything. Prefer it; use `read-command` only when a
read-only allowlisted command is enough.

## Quick reference

### Containers
```
run-command({profile:"docker-host", command:"docker ps -a --format '{{.Names}}\t{{.Status}}'"})
run-command({profile:"docker-host", command:"docker logs --tail 100 <name>"})
run-command({profile:"docker-host", command:"docker inspect <name>"})
run-command({profile:"docker-host", command:"docker exec <name> <cmd>"})
```

### Compose
```
run-command({profile:"docker-host", command:"docker compose -f /opt/docker-compose/<service>/docker-compose.yml ps"})
```

### Files
```
sftp-list({profile:"docker-host", remotePath:"/etc/docker/<service>"})
sftp-download({profile:"docker-host", remotePath:"/etc/docker/<service>/config.yml"})
```

### Git (`/etc/docker` is a Git repository)
```
run-command({profile:"docker-host", command:"git -C /etc/docker status --short"})
```

## Directory structure

```
/opt/docker-compose/<service>/   # docker-compose.yml (+ .env)
/etc/docker/<service>/           # service config + data
/etc/docker/                     # Git repository (hand-made configs)
```

## Sub-skills

- `docker-host-compose` – Compose project management
- `docker-host-filesystem` – file operations
- `docker-host-git` – Git in `/etc/docker`
